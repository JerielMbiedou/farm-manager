CONTEXTE :
Quand un éleveur saisit "Mangeoires", "Abreuvoir",
"Balance" etc. en dépense bande, il devrait être
redirigé vers les Actifs si la valeur dépasse le seuil.

3.1 — Liste des désignations d'équipements durables
Dans le frontend, créer une constante :

  const DESIGNATIONS_ACTIFS_POTENTIELS = [
    "mangeoire", "mangeoires",
    "abreuvoir", "abreuvoirs",
    "balance",
    "pompe",
    "groupe electrogene", "groupe électrogène",
    "generateur", "générateur",
    "réfrigérateur", "refrigerateur",
    "congélateur", "congelateur",
    "broyeur",

    "thermometre", "thermomètre",

    "incubateur",

3.2 — Alerte dans le formulaire de dépense bande
Dans bandes/[id].tsx, dans le formulaire d'ajout
de dépense, ajouter la logique suivante :

  // Récupérer le seuil depuis les paramètres
  const seuilActif = parseInt(
    parametres?.seuil_valeur_actif ?? "50000"
  );

  // Détecter si la désignation ressemble à un actif
  const designationNormalisee = designation
    ?.toLowerCase()
    .normalize("NFD")
    .replace(/[\u0300-\u036f]/g, "")
    .trim();

  const ressembleActif = DESIGNATIONS_ACTIFS_POTENTIELS
    .some(d => designationNormalisee?.includes(d));

  const montantSaisi = (quantite ?? 0) * (prixUnitaire ?? 0);
  const depasseSeuil = montantSaisi >= seuilActif;

  // Afficher l'alerte si les deux conditions sont réunies
  {ressembleActif && depasseSeuil && (
    <Alert className="border-blue-200 bg-blue-50 mt-2">
      <AlertTitle className="text-blue-800">
        💡 Cet équipement devrait-il être un Actif ?
      </AlertTitle>
      <AlertDescription className="text-blue-700">
        <strong>{designation}</strong> à{" "}
        {formatFCFA(montantSaisi)} dépasse le seuil de{" "}
        {formatFCFA(seuilActif)}. Les équipements durables
        (mangeoires, abreuvoirs, balance...) sont mieux
        gérés comme des <strong>Actifs amortissables</strong>
        : leur coût est réparti sur plusieurs bandes
        plutôt que chargé en une seule fois.
        <br />
        <Button
          variant="link"
          className="p-0 h-auto text-blue-700 underline"
          onClick={() => navigate("/infrastructure")}>
          → Enregistrer dans Infrastructure → Actifs
        </Button>
        <span className="ml-4 text-blue-600 text-xs">
          (ou continuer ici si c'est intentionnel)
        </span>
      </AlertDescription>
    </Alert>
  )}

L'alerte est informative — l'utilisateur peut
ignorer et continuer la saisie en dépense.

3.3 — Ne pas bloquer — juste informer
La saisie reste possible même si l'alerte est affichée.
Certains petits équipements en dessous du seuil
(marteau, pointes, sacs vides) restent en dépenses.

  UPDATE bande_depenses
  SET designation = TRIM(designation)
  WHERE designation != TRIM(designation);

  UPDATE chantier_depenses
  SET designation = TRIM(designation)
  WHERE designation != TRIM(designation);

  -- Apostrophes typographiques → ASCII
  UPDATE chantier_depenses
  SET designation = REPLACE(designation, ''', '''')
  WHERE designation LIKE '%'%';

4.4 — Nouvelles catégories chantier
  -- Restauration
  UPDATE chantier_depenses
  SET categorie = 'restauration'
  WHERE categorie = 'divers'
  AND LOWER(UNACCENT(TRIM(designation))) IN (
    'dejeuner', 'déjeuner', 'boisson',
    'boissons', 'repas'

  -- Eau
  UPDATE chantier_depenses
  SET categorie = 'eau'
  WHERE categorie = 'divers'

  UPDATE chantier_depenses

  WHERE categorie = 'divers'

  );

6.1 — Vérification sujets dans la route cloture
Dans bandes.ts POST /:id/cloture, avant d'accepter :

  const totalVendus = await db
    .select({ sum: sql`COALESCE(SUM(quantite_vendue), 0)` })
    .from(bandeVentesTable)
    .where(eq(bandeVentesTable.bandeId, bandeId));

  const sujetsRestants = bande.sujetsDepart
    - bande.nombreDeces
    - parseInt(totalVendus[0]?.sum ?? "0");

  // Retourner le warning si non-zéro
  const warning = sujetsRestants !== 0
    ? `${Math.abs(sujetsRestants)} sujet(s) ${
        sujetsRestants > 0 ? 'non comptabilisé(s)' :
        'en excès dans les ventes'
      } — vérifiez les ventes et mortalités.`
    : null;

  return res.json({ success: true, warning });
