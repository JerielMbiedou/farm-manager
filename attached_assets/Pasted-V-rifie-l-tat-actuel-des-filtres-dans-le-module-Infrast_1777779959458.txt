FILTRE 1 — Recherche texte libre
  Input placeholder : "Rechercher une désignation..."
  Filtre sur : designation (insensible casse + accents)

FILTRE 2 — Plage de dates
  Deux inputs type="date" :
  - "Du" (date début)
  - "Au" (date fin)
  Filtre sur : chantier_depenses.date
  Si date début seulement → tout depuis cette date
  Si date fin seulement → tout jusqu'à cette date
  Si les deux → entre les deux dates incluses

FILTRE 3 — Catégorie
  Select avec toutes les catégories présentes :
  Tous | Matériaux | Main d'œuvre | Carburant
  Transport | Restauration | Eau | Logistique | Divers
  Filtre sur : categorie

FILTRE 4 — Lot
  Select avec tous les lots du chantier :
  Tous les lots | [Lot 1] | [Lot 2] | ...
  Filtre sur : lot_id

BOUTON RÉINITIALISER
  Remet tous les filtres à leur valeur par défaut.
  Icône ×, affiché seulement si un filtre est actif.

EXPORT CSV
  Bouton "📥 Exporter"
  Télécharge TOUTES les dépenses filtrées
  (pas seulement la page courante)
  Format CSV :
    Date, Lot, Catégorie, Désignation, Qté,
    Prix unitaire, Montant, Commentaire
  Nom du fichier :
    depenses-[nom-chantier]-[date].csv
