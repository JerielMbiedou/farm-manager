4.1 — Partager les suggestions entre stocks et dépenses
La route GET /api/bandes/designations-suggestions
retourne déjà les désignations d'aliments utilisées
en dépenses bandes (Concentré, Aliment démarrage...).

Ces mêmes désignations devraient apparaître dans
le combobox des stocks aliments.

Dans GET /api/stocks/aliments/suggestions :
Merger aussi les désignations depuis bande_depenses
WHERE categorie IN ('aliments', 'concentre') :

  SELECT designation,
    ROUND(AVG(prix_unitaire::numeric), 0) as prix_moyen,
    SUM(COUNT(*)) OVER (PARTITION BY designation) as frequence
  FROM (
    SELECT designation, prix_unitaire
    FROM stock_aliments
    WHERE designation IS NOT NULL
    UNION ALL
    SELECT designation, prix_unitaire
    FROM bande_depenses
    WHERE categorie IN ('aliments', 'concentre')
    AND designation IS NOT NULL
  ) combined
  GROUP BY designation
  ORDER BY frequence DESC;

Ainsi l'éleveur retrouve ses désignations habituelles
qu'il vient de saisir en dépense ou en stock.
